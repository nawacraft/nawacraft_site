# nawacraft_site

Nawacraft official website and portfolio. Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting Started

First, install dependencies:

```bash
pnpm install
```

Then, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

To create a production build:

```bash
pnpm build
```
